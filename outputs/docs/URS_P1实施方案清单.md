## 〇、必须先说清的现实约束（连库实测）

设备 `1787816609` 数据**极其稀疏**：`metrics_1min` 24h 内真正有 ΔP/MP 的**通气分钟只有 23 个**，
且含一段 **14h 断流**（08-27 10:09 → 08-28 00:12）。相邻通气分钟间隔 1~843 min 不等。

由此对 P1 各项算法的**直接影响**：

| URS 原文口径 | 在稀疏数据下的事实 | 结论 / 我的建议 |
| :--- | :--- | :--- |
| 防抖 G1 ≥60min / G2 ≥30min / G3 ≥15min「持续」 | 现实中**根本不存在** ≥60 个**连续**真实通气分钟 | 「持续」必须改口径为 **「暴露累积分钟 / 有效通气分钟」**（用已含 ≤4h 前向填充的时间积分），而非要求连续的原始上报分钟 |
| CUSUM 用 X(t) 逐分钟递推 S± | 没有逐分钟序列，只有稀疏批次 | CUSUM 在**稀疏通气序列**上跑，x=真实时间戳；遇 >4h 断流 → **重置 CUSUM 状态**（断流本身记为「数据中断」，不作漂移） |
| 斜率 β 用 1h/6h/24h 滑动窗口 | 1h 窗口常只有 0~2 个点，回归不稳定 | 窗口按「**滑动时间窗**」，窗内点数不足(如 <3) 该档**置空/置 0**并标注「数据不足以回归」；6h/24h 更可靠 |
| 趋势图横轴真实时间 + 72h 档 | 数据跨度仅 18h（72h 档必空） | 72h 档照常提供 UI，但真实数据跨度不足时会显示「该时间窗仅覆盖 Xh」 |

> **一句话**：P1 所有算法都围绕「有效通气时间序列」而非「逐分钟网格」设计，
> 且凡涉"持续/连续"都需用时间积分口径 + 断流重置。

## 一、本次 P1 范围（建议）

### P1-A：趋势分析 —— 斜率 + CUSUM 变化点（URS FR-05）
**后端**（`calculator.py` + `api.py`）
1. 新增 `linear_slope(points_xy)` → 线性回归斜率 β（最小二乘）。
2. 新增 `window_slopes(rows, key, wins_h)`：对 ΔP/MP 分别算 6h / 24h（1h 因点数不足通常弃用）
   的**末尾滑动时间窗**斜率 β（cmH2O/h、J/min/h）；窗内有效点 < N_min(默认 3) → 返回 None + `insufficient`。
3. 新增 `cusum_change_points(rows, key, mu0_span_h, k, h, gap_reset_min)`：
   - 基线 μ0 = 过去 24h 有效均值；容差 k、控制限 h（URS 建议 ΔP:k=2,h=?、MP:k=2；h 默认 =5σ）。
   - 遇 >4h 断流重置状态（不累积到新段）。
   - 返回 `{points:[{ts, side, S}], baseline_mu0, k, h}`。
4. `/api/trends`（新端点）或扩展现有 `/api/dp/trend`+`/api/mp/trend`：每个返回点附 `slope` 与
   变化点标记，前端不再用 `diff>3` 启发式。

**前端**
- `fetchTrends` 改用后端返回的 CUSUM 变化点（替换现有 `|diff|>3` 循环）。
- 每个 ΔP/MP 页顶部/统计区显示「当前 6h/24h 斜率 β」+ 方向箭头 + 是否显著。

### P1-B：G0-G3 风险矩阵 + 防抖动（URS FR-06）
**风险矩阵重定义**（关键决策，需您拍板——见"四、待拍板"）
- 复用现有 4 级刻度（L1≈G0 / L2≈G1 / L3≈G2 / L4≈G3），但把**顶部总评**改为按 URS 的
  「24h 窗口 TAT」判据驱动：
  - G0: ΔP TAT<5h 且 MP TAT<7h（且瞬时未越限）
  - G1: ΔP≥15 持续≥60min（或 5≤TAT<15）/ MP≥17 持续≥60min（或 7≤TAT<17）
  - G2: ΔP TAT≥15 或 [ΔP≥15 持续≥30min 且 6h 斜率>0] / MP TAT≥17
  - G3: ΔP TAT≥30 或 ΔP≥20 持续≥15min / MP 按顺应性（高:≥18×2h，低:≥20×12h）
- 新增**防抖状态追踪**：对"持续超标"需维护「超标起始/累计时长」状态（落到 metrics_1min 或
  独立状态集合），时长用**有效通气分钟**口径；回落 <阈值 且维持 ≥10min → 自动解除。

**预警**
- `_check_and_alert` 去重从「5min 内同(级别,类别)」改为「G 等级变更才新报 + 防抖达标才报」，
  并支持**自动解除**（写入 resolved 状态，前端显示"已恢复"）。

### P1-C：界面（URS FR-07）
1. **顺应性分层标签卡**（原 P2 #13 提前）：总览新增「CRS 数值 + 高/低顺应性 + 特异性安全功率上限」

   「72小时」，并让「24h 默认视图」数据加载更符合所选档。
