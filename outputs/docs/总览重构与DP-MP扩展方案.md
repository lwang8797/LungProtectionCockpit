## 二、技术方案

### 2.1 16:9 不可滚动（需求 1）

- 外层 `.stage`：`width:100vw; height:100vh; display:flex; place-items:center; overflow:hidden`
- 内层 `.frame`：`aspect-ratio:16/9; width:min(100vw, calc(100vh*16/9)); height:auto; overflow:hidden`
- `.page{overflow:hidden}`；总览各卡高度压缩，用 `flex` 纵向分配（`flex:0 0 auto` + 图表 `flex:1 1 auto`）。
- 窄屏/超宽屏由 `min()` 保证 16:9 居中，两侧留白。
- **风险**：现有内容较多，压缩后可能仍溢出 → 两行卡设计为紧凑版（图高≈110px，指标用小网格）。

### 2.2 后端：分层风险结论接口（需求 2a/2b/3）

新增 `GET /api/exposure-summary?param=dp|mp&hours=1|6|24&deviceId=`
返回结构：

```json
{
  "param": "dp",
  "hours": 6,
  "stratum": "low",              // high/low（由 CRS 与 32.7 分界）
  "compliance_mean": 29.1,
  "series": [{"ts":..., "v":18.2, "over":true}, ...],   // 分钟均值（供左图）
  "metrics": {
    "tat_h": 3.4,                // 该窗口高暴露时长
    "auc": 12.6,                 // 超阈 AUC
    "pta": 41.2,                 // 高暴露占比 %
    "peak": 21.0, "mean": 14.3
  },
  "limits": {                     // 本层阈值（后端按分层给出）
    "instant_thr": 15.0,
    "tat_l3_h": 2.0, "tat_l4_h": 6.0,       // ΔP 固定；MP 随层变化
    "auc_ref": ...
  },
  "conclusion": {
    "level": 2,                  // 0-3
    "label": "L2 偏高",
    "hint": "ΔP 累积暴露已超本层 L3，呈持续上行",     // 风险提示
    "advice": "建议复核 VT/PEEP，评估驱动压来源",      // 建议
    "basis": "TAT 3.4h≥L3 2.0h；PTA 41%；趋势↑"     // 依据（简略）
  }
}
```

**分层判定（复用既有口径，不新造）**：
- `stratum = "high" if CRS > 32.7 else "low"`（`COMPLIANCE_STRATUM_THRESHOLD`）
- ΔP 轨道：阈值恒 15；L3=2h、L4=6h（`CUM_DP_OVER_HOURS_L3/L4`）
- MP 轨道：阈值随层 = 高顺应 18 / 低顺应 20；L3/L4 = 高 2h/6h、低 12h/24h
- 结论等级取 `max(瞬时维度, 累积维度)`，与 G0–G3 判级同源

**结论文案**（简略、按层与级别生成，后端拼装）：

| 级别 | 风险提示 | 建议 |
| :-: | :--- | :--- |
| L1 正常 | 暴露在安全范围 | 维持当前参数，常规监测 |
| L2 关注 | 接近本层安全上限 | 关注趋势，复核 VT/RR/PEEP |
| L3 偏高 | 累积暴露超本层 L3 | 建议下调 VT 或 RR，评估 PEEP |
| L4 危险 | 累积暴露达本层 L4 | 尽快个体化调整，评估肺保护策略 |

### 2.4 ΔP 页扩展（需求 5）

- 在 `dpChart`（分钟均值）下方新增 **累积 ΔP 曲线**（`<svg id="dpCum">`），口径对齐 MP 页累积机械能曲线：横轴真实时间、纵轴 σ(ΔP−15)·dt 累积（cmH₂O·h）。
- 复用现有 `drawTrend` 的时间轴与 tooltip 机制。
- MP 页累积机械能曲线保留不变。

### 2.5 扩展展示建议（需求 5b，肺保护角度）

拟新增（均按分层阈值着色/判级，**供你勾选**）：

1. **暴露-时间双视图**：瞬时曲线 + 累积剂量曲线同屏（ΔP/MP 各自），直观区分"此刻多大"与"累积多少"。
2. **PTA（percent time above）环形/条进度**：相对本层 L3/L4 的百分比，一眼看离危险还有多远。
3. **趋势方向箭头 + 斜率**：近似 1h/6h 斜率（复用 `/api/analysis` 的 `sliding_slopes`），提示"是否在上行"。
4. **预警关联标记**：把本窗口内的预警事件点标在曲线/时间带上（复用 `cockpit_alerts`）。
5. **驱动压分解**：ΔP = Pplat − PEEP 的两个分量随时间的贡献（若数据可得），提示是 PEEP 低还是 Pplat 高导致。
6. **单位化风险**（可选）：ΔP/VT（应变近似）、MP 归一化到理想体重（若录入体重），减少个体差异误读。
7. **可复评提示**：距上次参数调整的时长 + "建议复评"徽章（复用交接班逻辑，但只做提示不做整卡）。

> 以上 1–3 建议纳入本次实现（性价比高、不改后端大结构）；4–7 视你意愿决定是否纳入，或留作后续。
