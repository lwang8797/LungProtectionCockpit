## 三、拟实施方案（分 4 个交付块）

### 块 A｜累积剂量计双环表（URS 07-1）
- 在总览新增 **SVG 双环同心弧表**：外环半径大 = ΔP 累积剂量，内环 = MP 累积剂量。
- **四色分段**：绿(0–50%) / 黄(50–75%) / 橙(75–100%) / 红(>100%)，按"当前 TAT 占该等级阈值时长"的比例动态填充弧长。
- **中央文字**：ΔP `TAT x.x h / AUC xxx cmH₂O·h`、MP `TAT x.x h / AUC xxx J·h/min`（取 `cumulative.window.*`）。
- 保留现有两个瞬时值表（它们在风险/实时场景仍有价值），**双环表作为"累积剂量"主视觉置于其上方**。

### 块 B｜时变双轴折线热图升级（URS 07-2）
- **横轴改真实时钟**：用 `metrics_1min.minute` 做时间轴（等距时间而非等距点索引），稀疏数据下时间轴会正确留白/拉伸。
- **阈值红色阴影**：ΔP>15、MP>17 区域（曲线与阈值之间）填充半透明红，面积直观 = AUC。
- **CUSUM 漂移旗标**：消费 `/api/analysis` 的 `cusum.dp/mp.change_points`，在对应时间点绘制小旗 ⚑ + tooltip"基线漂移"。
- 时间档位：6h / 24h / 72h（已部分具备，补齐真实时间轴映射）。

### 块 C｜顺应性分层标签卡（URS 07-3）
- 独立卡片：显示 `CRS = xx.x mL/cmH₂O`、分组标签（高顺应性肺·剂量敏感型 / 低顺应性肺·窄带耐受型）、
  以及**该分层的安全功率上限**（高顺应性 MP<18 J/min；低顺应性 MP<20 J/min，含对应 TAT 阈值 2h/12h）。
- 与现有 URS 分析卡的 stratum 文案统一口径（共用 `grade.stratum`），避免两处结论打架。

### 块 D｜交接班摘要与导出（URS 07-4）
- **后端新增** `GET /api/shift-summary?hours=8|12|24`，返回：本班次 ΔP/MP 最高暴露、超标总时长(TAT)、AUC 增量、趋势斜率方向（升/平/降 + β）、预警干预记录（条数 + 明细）。
- **前端新增**「交接班摘要」卡片：8h/12h/24h 三档切换 + 一键**导出**。
- 导出格式：**先做 CSV**（分钟级明细 + 汇总头），后续按需再做 HTML/PDF 交接单。
- 同步把现有两个 `导出 CSV` 占位按钮接到真实实现（不再只是 toast）。

## 四、需要你拍板的 3 个待定项

**① 双环"满量程"如何定义？**（决定四色填充比例的分母）
- 选项 A（推荐）：用**该分层的高暴露小时阈值**作满量程 —— ΔP 外环以 `CUM_DP_OVER_HOURS_L4=6h` 为满环，
  MP 内环以分层 L4 阈值（高顺应性 6h / 低顺应性 24h）为满环。→ 语义="距离 L4 危险还有多远"，临床直观。
- 选项 B：固定 24h 满环（当日已过时间占比语义）。
- 选项 C：先用 A，我在设置页留可调参数。

**② 现有两个瞬时值半圆表如何处理？**
- 选项 A（推荐）：**保留**，双环累积表在其上方作为主视觉（信息互补：一个是"此刻"，一个是"累积"）。
- 选项 B：移除，只留双环表（更贴近 URS"单屏解构"、降低认知负荷），瞬时数值改用紧凑数字卡展示。

**③ 后端是否新增 `/api/shift-summary`？**
- 选项 A（推荐）：**新增后端接口**（8/12/24h 汇总在服务端算，前端只渲染 + 导出，口径与 URS G0–G3 防抖一致）。
- 选项 B：纯前端用现有 `/api/metrics/1min` 聚合（少改后端，但口径易与后端判级不一致）。

## 五、影响与风险
- 块 B 改真实时间轴后，稀疏数据（新设备刚上线、仅几分钟）下趋势图点会很稀疏，属预期；
  这恰好能真实反映"数据断流"，与 URS FR-01 断流口径一致。
- 块 D 涉及后端新增接口 + 前端联调，改动面最大，建议放在最后做。
- 所有改动保持现有 API 契约不变（`/api/overview` 等），不影响已验证的预警确认功能。
