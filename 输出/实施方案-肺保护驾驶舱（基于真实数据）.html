2. 更新后的计算方案

2.1 ΔP（驱动压）计算

策略：设备直读优先 + 计算备用
# 优先使用设备直接测量的 DrivePress
dp = row["DrivePress"]  # paramId=160

# 备用：Pplat - PEEP（当 DrivePress 缺失时）
if isnan(dp):
    dp = row["Pplat"] - row["PEEP"]  # paramId=102 - 104

阈值：ΔP ≥ 15 cmH₂O（Amato 2015 NEJM）

2.2 MP（机械功率）计算

简化机械功率公式（Chi 2025 Chest）
MP = 0.098 × RR × VT_L × (PIP − 0.5 × ΔP)

# 参数来源：
#   RR  = ftotal (paramId=113, bpm)     ← 替代 PR(128)
#   VT  = Vte   (paramId=106, mL → /1000 → L)
#   PIP = Ppeak  (paramId=101, cmH₂O)
#   ΔP  = DrivePress (paramId=160, cmH₂O)

rr = row["ftotal"]      # 总呼吸频率
vt_l = row["Vte"] / 1000.0
pip = row["PIP"]
dp = row["dP"]          # 已计算的 ΔP
mp = 0.098 * rr * vt_l * (pip - 0.5 * dp)

阈值：MP ≥ 17 J/min（Chest 2025）

2.3 累积暴露指标

指标计算方法单位含义
AUC（超标曲线下面积）梯形法 Σ max(0, val−threshold) × dtcmH₂O·min / J·min⁻¹·min超标累积量
时间超阈占比count(val > threshold) / total × 100%超标时间比例
累积机械能Σ MP × dt_minJ总能量输入
风险评级L1~L4 四级—综合风险等级

5.2 M2 聚合服务设计要点

# 每分钟执行一次，处理上一分钟的原始数据
def aggregate_minute(device_id, minute_start):
    end = minute_start + 60000  # 1min

    # 1. 采集该分钟原始数据
    rows = collect(device_id, minute_start, end)

    # 2. 计算 ΔP/MP
    for row in rows:
        calculate_dp_mp(row)

    # 3. 过滤待机
    vent_rows = [r for r in rows if r["dP"] > 0]

    # 4. 聚合统计
    stats = {
        "dp_mean": mean(r["dP"] for r in vent_rows),
        "dp_max": max(r["dP"] for r in vent_rows),
        "dp_over_pct": count_over / len(vent_rows) * 100,
        "mp_mean": mean(r["MP"] for r in vent_rows),
        ...
    }

    # 5. 累积量滚动（从上一分钟读取累积值）
    prev = db.metrics_1min.find_one(
        {"deviceId": device_id}, sort=[("minute", -1)]
    )
    stats["cumulative_energy"] = (prev["cumulative_energy"] if prev else 0) \
        + stats["mp_mean"] * len(vent_rows) * 4 / 60

    # 6. 写入
    db.metrics_1min.update_one(
        {"deviceId": device_id, "minute": minute_start},
        {"$set": stats}, upsert=True
    )

8.2 缺口：总览页报警仍为「单值阈值」，未用累积暴露

核查结论：用户判断正确。 总览页的 ΔP/MP 风险判定与报警，目前全部基于单值阈值，累积暴露指标虽已在后端计算并返回，但未参与总览页的报警/评级决策。具体证据（均来自源码）：
  • 风险评级来源：前端 risk_level 直接取后端 classify_risk 结果；该函数在 calculator.py 中仅依据 dp_max/mp_max 是否超阈、以及 over_pct（超阈占比）分级 —— 均为单点/单值维度。
  • 报警条幅/风险芯片：前端 updateOverviewUI 用 d.dp.current >= d.dp.threshold、d.mp.current >= d.mp.threshold 判定「超限」——瞬时单值。
  • 仪表盘徽标：dpVal >= TH.dp 等，单值阈值。
  • 24h 风险时间带：逐点 riskOf(dp,mp)（dp>=TH.dp || mp>=TH.mp），单值。
  • 后端预警：aggregator._check_and_alert 触发条件为 risk_level>=2（单值阈值派生）；消息文案只列「最大/超阈占比」。
  • 累积量去向：后端 cumulative 对象（cumulative_energy_j / dp_auc / mp_auc / vent_duration_min）已随 /api/overview 返回，但前端仅用 vent_duration_min 显示「通气时长」，其余累积指标未用于任何报警或评级；MP 趋势页的「累积机械能曲线」仅为可视化，非报警。
因此：「ΔP/MP 累积暴露」作为项目定位，在计算与可视化层已落地，但在总览页报警决策层尚未落地。

9. 累积暴露报警接入总览页（已实施 · 2026-08-27，方法据医师文献精读 v3）

本节方案已落地。用户确认采用「双维度合并风险」；累积暴露阈值按用户要求保留在「设置」页、可随时设置与修改，当前为保守默认、待临床（医师）最终确认。2026-08-27 医师反馈的文献精读（水相《ΔP/MP 暴露累积原始文献与实现逻辑》）将累积暴露度量由"总机械能/总AUC"修正为"高暴露小时数 + 顺应性分层"，并明确 MP 公式优先静态 ΔP，本版已据此实现。

9.1 目标

让总览页的 ΔP/MP 风险评级与报警，同时反映「瞬时单值阈值」与「累积暴露」两个维度；后端预警区分 threshold（单值越限）与 cumulative（累积暴露越限）两类，使项目定位（ΔP/MP 累积暴露）与总览行为一致。

9.2 总体设计：双维度、合并风险

维度输入判定
瞬时维度（已有）dp_max / mp_max / over_pct单值阈值 → L1–L4（超阈占比>20%→L3、>50%→L4）
累积维度（双轨）ΔP 高暴露小时数；MP 高暴露小时数（按顺应性分层）高暴露小时数越过 L3/L4 → L1/L3/L4
合并—risk_level = max(瞬时, 累积)（任一维度危险即危险）

9.3 累积暴露度量（据 2026-08-27 文献精读）

  • 度量 = 高暴露小时数：1 分钟聚合下累加"指标≥阈值的分钟数"，÷60 得小时数。文献最小时间单位=小时（Lijovic 2026 / Tan 2024），无"连续 N 分钟"直接文献支持。
  • ΔP 轨道：阈值统一 15 cmH₂O（Amato 2015）；高暴露 ≥2h → L3、≥6h → L4（Lijovic 2026 高顺应性类推）。
  • MP 轨道（顺应性分层，Lijovic 2026）：CRS = Vte / ΔP，分界 32.7 mL/cmH₂O。
    • 高顺应性（CRS>32.7）：MP≥18 且 高暴露 ≥2h → L3、≥6h → L4；
    • 低顺应性（CRS≤32.7）：MP≥20 且 高暴露 ≥12h → L3、≥24h → L4。
  • MP 公式：Gattinoni 标准 0.098·RR·VT·(Ppeak−0.5·ΔP)，ΔP 优先取静态（Pplat−PEEP），无 Pplat 时回退设备直读/动态 ΔP。
  • 辅助指标：超阈 AUC（ΔP/MP）、总机械能（kJ）、% 时间超阈，用于展示与核查（不直接驱动风险）。

9.4 改动清单（v3 已落地）

后端（config.py / calculator.py / aggregator.py / api.py）

  • config.py：累积暴露阈值改为高暴露小时数 + 顺应性分层（见 9.5）。
  • calculator.py：calculate_dp 静态优先；compute_exposure 计算高暴露分钟数(dp/mp17/18/20)、超阈 AUC、总机械能、顺应性均值；classify_cumulative_risk(dp_over_hours, mp_over_hours, stratum) 按轨道+分层判定 L1/L3/L4。
  • aggregator.py：每分钟滚动累积新字段（cum_dp_over_min / cum_mp_over_min_18/20 / cum_*_auc_above / cum_energy / compliance_mean），合并风险按顺应性分层；_check_and_alert 累积文案改为高暴露小时数+分层。
  • api.py：/api/overview 与 /ws 的 cumulative 块改为高暴露小时数 + 顺应性分层 + 默认阈值，两条路径一致。

前端（cockpit_frontend.html）

  • 总览页「累积暴露」卡片：展示 ΔP/MP 高暴露时长(h)、累积机械能(kJ)、通气时长，及顺应性分层徽标（高/低 + CRS）。
  • 风险评级/报警条幅/风险芯片：采用合并风险，文案区分「单值越限」「累积暴露越限（高暴露 Xh）」。
